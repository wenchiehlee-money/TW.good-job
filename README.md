# TW.good-job

本 repo 用來保存與求職公司調查相關的本地技能與使用說明。

## 目前技能

- [`skills/skill-company-reputation-research`](skills/skill-company-reputation-research)：針對指定公司彙整台灣及全球求職者常用管道，整理公司聲譽、面試流程、薪資工時、工作氛圍、勞資風險與職涯適配性。

## 使用方式

在 Codex / ChatGPT 中指定 skill 名稱與公司、職缺、年資即可：

```text
使用 skill-company-reputation-research，幫我查「力旺」給 2 年資歷工程師是否值得去。請重點看薪資、工時、面試流程、部門文化、職涯風險，並附來源。
```

比較多家公司：

```text
使用 skill-company-reputation-research，比較「力旺、新代、晶焱」給 2 年 engineer 的 offer 吸引力。請用表格整理薪資、工時、成長性、風險，最後給排序與追問清單。
```

準備面試：

```text
使用 skill-company-reputation-research，幫我準備「公司名稱」「職稱」面試。請整理常見筆試/面試題、需要複習的科目、薪資談判重點，以及我應該反問主管的問題。
```

更多細節請看 [`skills/skill-company-reputation-research/README.md`](skills/skill-company-reputation-research/README.md)。
